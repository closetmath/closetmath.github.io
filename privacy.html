Privacy Policy

Last updated: 9 November 2026

This policy covers Closet Math Uploader ("the tool"), which we use to publish videos to the Closet Math YouTube channel.

Who uses it

Only the owner of the Closet Math channel. It isn't available to the public and nobody else can sign in to it.

YouTube API Services

The tool uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's privacy policy applies to any data YouTube handles and is available at https://policies.google.com/privacy.

What it accesses

With the channel owner's permission, given through Google's sign-in screen, the tool uses the YouTube Data API to upload videos, set thumbnails, add captions and confirm which channel is connected. It doesn't read, collect or store data about viewers or any other YouTube users or channels.

What it stores

It stores one sign-in token for the Closet Math channel, on our own server, so it can publish on schedule. It also keeps a list of the IDs of videos it has uploaded. Nothing else is stored, and nothing is shared with or sold to anyone.

Cookies

The tool has no website interface and sets no cookies. This website sets no cookies either.

Revoking access and deleting data

The channel owner can revoke the tool's access at any time from the Google security settings page at https://security.google.com/settings/security/permissions. When access is revoked, or on request by email, we delete the stored sign-in token and upload records within 7 days. We also refresh or delete any stored API data at least every 30 days, as YouTube's developer policies require.

Contact

Questions or deletion requests: closetmath.channel@gmail.com
